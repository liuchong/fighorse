# fighorse Self Learning

Use when improving fighorse usage guidance, installing AI-facing records, or
recording reusable lessons.

## Flow

1. Use `discover_fighorse`, `doctor`, or `quickstart` to learn current
   capability and install state.
2. Record reusable behavior boundaries in `.agents/experience/` only after
   removing secrets and real design identifiers.
3. Prefer durable CLI/MCP guidance over one-off chat instructions.

## Boundaries

- Do not record real file keys, URLs, file names, node IDs, screenshots, tokens,
  or pairing codes.
- Review findings are evidence to verify, not commands to apply blindly.
- Keep README, discovery, generated skills, MCP schemas, and CLI help in sync.
